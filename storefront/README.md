# Wave Marketplace

This is the frontend for Wave Marketplace, built using Next.js.

## Getting Started

To get started with the Wave Marketplace frontend, follow these steps:

1. **Clone the Repository**  
   `git clone https://github.com/ainatunde/wave-marketplace.git`

2. **Navigate to the Project Directory**  
   `cd wave-marketplace`

3. **Install Dependencies**  
   Run the following command to install all the necessary dependencies:
   ```bash
   npm install
   ```

4. **Run the Development Server**  
   Start the Next.js development server using:
   ```bash
   npm run dev
   ```

5. **Open Your Browser**  
   Navigate to `http://localhost:3000` to see your application in action.

## Building for Production

To create an optimized build for production, run:
```bash
npm run build
```
This command will compile your application and optimize it for performance.
