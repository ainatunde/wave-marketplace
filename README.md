# Wave Marketplace

## Project Overview
Wave Marketplace is an online platform dedicated to showcasing and selling Nigerian art. Our vision is to empower local artists and connect them with a global audience while providing unique and culturally rich art pieces to art enthusiasts.

## Tech Stack
- **Medusa:** A headless commerce framework that provides flexibility and scalability for building modern e-commerce applications.
- **Next.js:** A React framework that enables server-side rendering, static site generation, and optimized performance.
- **PostgreSQL:** A powerful relational database system that ensures data integrity and supports complex queries.

## Features
- **Curated Art Collections:** Explore a diverse range of art from talented Nigerian artists, with categories spanning traditional to contemporary pieces.
- **Artist Profiles:** Learn about the artists behind the works, including their backgrounds and creative processes.
- **Secure Transactions:** A safe and seamless purchasing experience for customers, with multiple payment options.
- **User-Friendly Interface:** An easy-to-navigate platform that enhances the art browsing experience.

## Setup Instructions
1. **Clone the Repository**  
   ```bash  
   git clone https://github.com/ainatunde/wave-marketplace.git  
   ```  
2. **Install Dependencies**  
   Navigate to the project directory and install the required packages:  
   ```bash  
   cd wave-marketplace  
   npm install  
   ```  
3. **Set Up Environment Variables**  
   Create a `.env` file in the root of the project with your database and API keys.
4. **Run the Application**  
   Start the development server:  
   ```bash  
   npm run dev  
   ```  
5. **Access the Application**  
   Open your browser and go to `http://localhost:3000` to view your project.
